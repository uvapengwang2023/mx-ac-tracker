## 有效做法

1. 先固定文件命名规则：`序号_文件名_时间戳`。这样每次采集都有独立批次，不会把上次结果覆盖掉。
2. 先把上次 Elite 2 的整理结果作为历史输入，再把新 PDF 展开到同一套字段，避免同系列散落在多个文件里。
3. PDF 规格表不能只依赖文字抽取。文字流容易打乱列顺序，本次同时渲染规格页截图，逐项核对型号、冷媒充注量、尺寸和异常值。
4. 核心参数和扩展参数分表保存。核心表用于电商/竞品横向比较，扩展表保留风量、噪音、管径、包装尺寸、毛重等更细字段。
5. 保留源文件路径和 URL。后续复核时可以直接回到 PDF 或本地快照，不必重新搜索。

## 字段口径

- `型号/表头` 使用 PDF 表头或上次整理中的型号后缀，如 `121-E4`、`362-K`。
- `SEER或REEE_W/W` 兼容 Elite 4 PDF 中的 `REEE` 和 Trendy 系列中的 `SEER`，用于同类能效字段汇总。
- `冷媒_原文` 保留源文件写法，如 `R410/600g`；`冷媒类型_规范` 统一为 `R410A`，便于筛选。
- 尺寸字段保持源文件顺序。2025 PDF 明确写为 `ancho x alto x fondo` 或 `ancho x profundidad x alto`，工作簿中不强行改序。
- 缺失字段留空，不用推算值填充，避免把来源没有提供的信息误当成采集值。

## 需复核的源文件异常

- `TRENDY_K_POPUP.pdf`：`362-K` 的 `SEER` 显示为 `2.2`，低压显示 `50 MPa`，室内低档噪音显示 `58 dB(A)`；这些值已按 PDF 可见值保留，但建议向品牌页或说明书二次确认。
- `TRENDY_3_POPUP.pdf`：12K 列表头为 `122-T3`，但型号格显示 `EMPRC121-T3 / EMPRN121-T3 / CMPRC121-T3 / CMPRN121-T3`；本次保留源文件写法，并在备注中标注。
- `ELITE_4_POPUP.pdf`：文字抽取中 `122-E4` 冷媒充注量顺序容易错位，已用渲染页核对为单冷 `0.45 kg`、冷暖 `0.65 kg`。

## 下次建议

1. 每新增一个 PDF，先保存源文件到 `data/prime/source_pdfs/`，再做结构化整理。
2. 对所有疑似异常值建立 `备注`，不要静默修正。
3. 后续如果继续补 Home Depot、Walmart、Coppel 商品页，可用 `品牌 + 系列 + 型号/表头 + 电压 + BTU` 作为去重键。
4. 若需要电商上架表，建议从当前核心表再派生一个轻量 SKU 表，只保留型号、BTU、电压、冷媒、尺寸、重量、能效和来源字段。
